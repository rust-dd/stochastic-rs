`DistributionExt` is `f64`-only (not generic over `T`), and every method returns `Option` and defaults to `None` — a distribution overrides only the methods it has a closed form for:

```rust
// Every method is provided and defaults to None; a law overrides the ones it has a closed form for.
pub trait DistributionExt {
  fn characteristic_function(&self, t: f64) -> Option<Complex64>;
  fn pdf(&self, x: f64) -> Option<f64>;
  fn cdf(&self, x: f64) -> Option<f64>;
  fn quantile(&self, p: f64) -> Option<f64>;
  fn mean(&self) -> Option<f64>;
  fn median(&self) -> Option<f64>;
  fn mode(&self) -> Option<f64>;
  fn variance(&self) -> Option<f64>;
  fn skewness(&self) -> Option<f64>;
  fn kurtosis(&self) -> Option<f64>;
  fn entropy(&self) -> Option<f64>;
  fn moment_generating_function(&self, t: f64) -> Option<f64>;
}
```

## Coverage

**32 of the 36** distribution types implement `DistributionExt`. The four that do not are `SimdDirichlet` and `SimdWishart` (vector- and matrix-valued draws, with their own inherent `pdf` / `log_pdf`), `SimdNonCentralChiSquared` (its noncentrality is supplied per draw) and `ComplexDistribution` (pairs two distributions as the parts of a complex draw).

Implementing the trait does not mean every method has a closed form: eight laws (`SimdCauchy`, `SimdChiSquared`, `SimdExp`, `SimdGamma`, `SimdGeometric`, `SimdNormal`, `SimdPoisson`, `SimdUniform`) answer all twelve methods, and the other twenty-four answer `None` on specific methods (a GED characteristic function, a Skellam quantile).

## A missing closed form is None, never zero

A quantity the law has no closed form for is `None`, never a silent `0.0` and never a panic, so generic code can test for it. `Some(NaN)` means the quantity provably does not exist (the Cauchy mean) or the argument is outside the method's domain.
