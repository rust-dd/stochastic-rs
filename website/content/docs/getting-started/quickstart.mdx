Three short examples, each in Rust and Python.

## 1. Simulate an OU path

The Ornstein-Uhlenbeck process

$$ dX_t = \theta(\mu - X_t)\,dt + \sigma\,dW_t,\quad X_0 = x_0 $$

with $\theta = 2$, $\mu = 0$, $\sigma = 1$, $X_0 = 0$, on $t \in [0, 1]$ with 1000 grid points:

### Rust

<RustExample path="tests/doctest_quickstart_ou.rs" />

### Python

```python
import stochastic_rs as srs

p = srs.PyOu(theta=2.0, mu=0.0, sigma=1.0, n=1000, x0=0.0, t=1.0)
path = p.sample()
print("len =", path.shape[0], "mean =", path.mean())
```

The [Processes catalog](/docs/processes) lists the rest.

## 2. Price a Heston European call

`HestonPricer` evaluates the semi-closed form of Heston (1993). The struct holds the model; the query `(s, k, r, q, tau)` goes to each call.

### Rust

<RustExample path="tests/doctest_quickstart_heston.rs" />

### Python

```python
import stochastic_rs as srs

pricer = srs.HestonPricer(
    s=100, v0=0.04, k=100, r=0.03, kappa=2.0, theta=0.04, sigma=0.3,
    rho=-0.5, tau=1.0, q=0.0,
)
call, put = pricer.call_put()
print(f"call={call:.4f}, put={put:.4f}")
```

## 3. Estimate Hurst from a fractional-Brownian path

The rescaled-range estimator (Hurst 1951, with the Anis-Lloyd 1976 bias correction) estimates the Hurst exponent of a sampled path. It is one of eight implementors of the `HurstEstimator` trait. Do not use `Whittle` for this: it estimates the roughness of latent volatility from a realized-variance series, not the Hurst exponent of a path (see [the statistics page](/docs/stats#hurst-exponent-estimation)).

### Rust

<RustExample path="tests/doctest_quickstart_hurst.rs" />

### Python

```python
import stochastic_rs as srs
import numpy as np

fgn = srs.PyFgn(hurst=0.3, n=4096, t=1.0, seed=7)
fbm = np.cumsum(fgn.sample())
res = srs.RescaledRange().estimate(fbm)   # differences the path internally
print(f"H = {res.hurst:.3f} (true 0.3)")
```
