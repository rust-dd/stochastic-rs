# Distributions

The `stochastic-rs-distributions` crate ships **19 user-facing
distributions**, every one of them with:

- A `Simd<Name><T>` struct that implements `rand_distr::Distribution<T>`
- A bulk filler `fill_slice(dst)` that draws from the distribution's own
  internal RNG (no separate `rng`-explicit / `_fast` pair)
- A
  [`DistributionExt`](/docs/concepts/distribution-ext)
  impl with closed-form pdf / cdf / characteristic function / moments
- A `py_distribution!`-generated `#[pyclass]` for Python use
- A KS-test against the analytic CDF

## The list

### Continuous

| Distribution                | Strategy                                  |
|-----------------------------|-------------------------------------------|
| Normal                      | Ziggurat                                  |
| Lognormal                   | Transformation (`exp(N)`)                 |
| Cauchy                      | Inversion                                 |
| Student-t                   | Composition ($Z / \sqrt{\chi^2_\nu/\nu}$) |
| Exponential                 | Ziggurat                                  |
| Gamma                       | Marsaglia-Tsang squeeze                   |
| Beta                        | Gamma-ratio composition                   |
| Chi-squared                 | Composition (Gamma)                       |
| Non-central chi-squared     | Composition ($\chi^2_{\nu-1} + (Z+\sqrt\lambda)^2$) |
| Inverse Gaussian            | Michael-Schucany                          |
| Pareto                      | Inversion                                 |
| Weibull                     | Ziggurat (Exp) + power transform          |
| Uniform                     | Inversion (trivial)                       |
| Alpha-stable                | Chambers-Mallows-Stuck                    |
| Normal Inverse Gaussian     | Inverse-Gaussian mixture                  |

### Discrete

| Distribution        | Strategy                                     |
|---------------------|----------------------------------------------|
| Binomial            | BTRS rejection / geometric waiting-time      |
| Geometric           | Inversion                                    |
| Poisson             | Inverse transform (precomputed CDF table)    |
| Hypergeometric      | Inverse transform (precomputed CDF table)    |

## Common patterns

### Construction

Every distribution follows the same `new(args, &seed)` constructor pattern — pass
[`Unseeded`](/docs/concepts/seeding) for an auto-seeded RNG or
[`Deterministic::new(u64)`](/docs/concepts/seeding) for a reproducible
stream. See the [seeding concept page](/docs/concepts/seeding) for the
full design (including `SeedExt::reseed`, the generic `R: SimdRngExt`
backing RNG, and the experimental `dual-stream-rng` feature). `Foo` and
`d` below stand for any distribution and its instance — the general
shape, not a concrete type — so this pattern is not wired into the
compiled-example mechanism the way the catalog entries above are:

```rust
use stochastic_rs::simd_rng::{Deterministic, Unseeded};

let d = Foo::<T>::new(/* params */, &Unseeded);                       // auto-seeded
let d = Foo::<T>::new(/* params */, &Deterministic::new(42));         // reproducible
let d = Foo::<T>::new(/* params */, &shared_seed_source);             // share a seed source
                                                                       // across sub-components
```

### Sampling

```rust
use rand_distr::Distribution;

// Single sample, via the project's own RNG (see the seeding concept page)
let mut rng = Deterministic::new(0).rng();
let x: f64 = d.sample(&mut rng);

// Bulk fill (uses the distribution's own internal RNG, applies SIMD)
let mut buf = vec![0.0_f64; 10_000];
d.fill_slice(&mut buf);
```

### Closed-form analytics

`DistributionExt` is `f64`-only (not generic over `T`) and every method
defaults to a `type_name`-annotated `unimplemented!()`, overridden per
distribution where a closed form exists:

```rust
use stochastic_rs::traits::DistributionExt;

let pdf = d.pdf(0.5);
let cdf = d.cdf(0.5);
let cf  = d.characteristic_function(2.0);    // Complex64
let m1  = d.mean();
let m2  = d.variance();
```
