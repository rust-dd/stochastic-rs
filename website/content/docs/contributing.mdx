Contributions are welcome. A PR that adds a public type ships with:

1. The implementation, with a paper citation in the source file.
2. A comparison test against the cited paper's numerical example.
3. A criterion bench under `benches/`.
4. A docs section under `website/content/docs/`, following the templates in the [`docs-writing`](https://github.com/rust-dd/stochastic-rs/blob/main/.claude/skills/docs-writing/SKILL.md) SKILL.
5. A Python wrapper if the type is user-facing (per the [`python-bindings`](https://github.com/rust-dd/stochastic-rs/blob/main/.claude/skills/python-bindings/SKILL.md) SKILL).

## SKILLs — the per-feature recipes
